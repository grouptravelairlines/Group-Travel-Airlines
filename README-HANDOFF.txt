# Group Travel Airlines — Web 2.0 GitHub Pages Starter

## What this package contains
- `index.html` — redesigned homepage
- `blog.html` — single Travel Blog category page
- `blog/` — starter article pages
- `assets/logo.png` — supplied Group Travel Airlines white logo

## Design direction
- Deep navy brand foundation
- Cobalt blue secondary accent
- Teal support accent
- Warm gold CTA accent
- Soft blue/white page backgrounds
- Rounded Web 2.0 cards, glass effects and soft shadows
- No external framework or build process

## GitHub upload
Upload all files while preserving this structure:

Group-Travel-Airlines/
  index.html
  blog.html
  assets/
    logo.png
  blog/
    how-to-book-group-flights.html
    group-travel-tips.html
    airline-group-reservations.html

Then enable GitHub Pages:
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Important
The article pages are starter templates. Replace their placeholder copy with approved, researched article content before publishing.

The quote form currently uses a `mailto:` action for a simple static-site setup. For a real server-side form, connect a form service or backend later.
